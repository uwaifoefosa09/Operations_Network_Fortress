
# Operations_Network_Fortress
A simulated enterprise network infrastructure project built with Cisco Packet Tracer, featuring VLAN segmentation, inter-VLAN routing, OSPF, network security, DHCP, DNS, and centralized network management.

## Enterprise Network Infrastructure Project

A simulated enterprise network infrastructure project built with Cisco Packet Tracer. This project explores enterprise switching, routing, network segmentation, infrastructure services, and network security.

## Project Objectives

The objective is to design, configure, and troubleshoot a simulated enterprise network that demonstrates practical networking concepts covered in the Cisco CCNA curriculum.

## Technologies & Protocols

- Cisco Packet Tracer
- VLANs and Inter-VLAN Routing
- IEEE 802.1Q Trunking
- EtherChannel (LACP)
- Spanning Tree Protocol
- OSPF Routing
- DHCP and DHCP Relay
- DNS Services
- Access Control Lists (ACLs)
- SSH Remote Management
- Port Security
- Wireless LAN Controller (WLC)

## Implementation Highlights

### 1. Network Segmentation
Implemented VLAN-based segmentation to separate departments and network resources.

### 2. Switching Infrastructure
Configured trunk links, EtherChannel, and switching infrastructure.

### 3. Routing
Implemented inter-VLAN routing and OSPF to facilitate communication between network segments.

### 4. Network Security
Explored ACL-based traffic filtering, SSH management access, and Layer 2 security mechanisms.

### 5. Infrastructure Services
Configured DHCP, DHCP relay, and DNS services.

### 6. Wireless Infrastructure
Explored controller-based wireless networking using a WLC and lightweight access points.
